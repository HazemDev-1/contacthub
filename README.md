# ContactHub - Contact Manager

A contact manager with full create, read, update and delete.

**Stack:** JavaScript, Bootstrap 5

**Live demo:** https://hazemdev-1.github.io/contacthub/

## Features

- Add, edit, delete and search contacts
- Form validation before saving
- Data persisted in localStorage so it survives a refresh

## Run it

No build step. Open `index.html` in a browser, or use the VS Code Live Server extension.
